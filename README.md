# ai-strategy-diagram-skill
把 AI 产品经理 PRD 里的策略说明、推荐逻辑、投流承接、Feed 混排、画像体系、标签映射等内容，转成领导一眼能看懂的白底大厂风策略图。

这个 skill 适合中文产品经理在写 PRD、方案评审材料、钉钉文档时使用。它不会生成复杂技术架构图，而是帮助你把策略逻辑抽象成清晰的“入口 -> 判断 -> 分流 -> 承接 -> 结果”图示。

## 适合场景

- PRD 背景与目标需要配一张概述图
- 推荐策略、Feed 混排策略、承接链路需要讲清楚
- 投流素材标签需要映射到端内落地页、模板标签或推荐内容
- 用户分层、画像体系、规则优先级需要可视化
- Before / After 现状问题与新策略优化需要对比
- 想把一段产品方案文字转成 Mermaid、PPT AI、Figma AI、Napkin AI 或 Excalidraw AI 可用的制图提示词

## 输出内容

默认会输出：

1. 是否建议画图，以及推荐图类型
2. 一句话图意
3. 图结构草稿
4. Mermaid 基础流程图代码
5. 高级感 AI 制图 Prompt
6. 图中文字压缩建议

## 视觉风格

- 纯白背景
- 横向宽图
- 大厂 PRD / 轻咨询风
- 黑灰色表达普通链路
- 蓝色表达新策略、核心优化、正向能力
- 红色表达问题、断点、风险
- 紫色表达 Feed 内容卡、业务模块或混排示意
- 图中文字尽量短，不直接塞 PRD 长句
